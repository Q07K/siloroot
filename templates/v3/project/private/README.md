# 개인 영역

나만 보는 문서를 둔다. 이 폴더는 git에서 빠져 있다(`.git/info/exclude`).

| 폴더 | 무엇이 있나 |
| --- | --- |
| `private/log/` | 작업 기록(`changelog.md`)과 사용자 확인이 필요한 것(`open-questions.md`) |
| `private/sources/` | 받은 자료, 회의 메모처럼 다른 문서의 근거가 되는 원본 (`source`) |
| `private/notes/` | 개인 메모 (`note`) |
| `private/discussions/` | 사용자와 의견을 주고받은 논의 기록 (`note`) |
| `private/feedback/` | 이 작업 공간 문서에 뷰어에서 남긴 댓글 (`feedback`) |

댓글 형식과 처리 절차는 홈의 `home:feedback/README.md`와 `/siloroot:feedback`을 따른다. 글쓰기 규칙 후보와 사용자 정보 후보는 여기가 아니라 홈 `feedback/`에 만든다.
