# 제품 아이디어

이 프로젝트에서 만들 것. 아이디어 하나에 문서 하나. 흩어져 나와도 된다.

## 여기에 넣는 것

- 만들고 싶은 것, 왜, 떠오른 생각
- 아이디어 안의 작은 결정은 그 문서의 "정한 것" 표

## 여기에 넣지 않는 것

- 따로 남길 결정 → `shared/decisions/`
- 설계 → `shared/design/`
- 구현 계획 → `shared/plans/`
- 측정과 실험 → 결정 기록의 근거, 개념은 홈 공부 노트
- 개인 아이디어(사용자가 말한 것) → 홈의 개인 아이디어

## 파일 이름과 상태

- 파일: `영문-이름.md`. 만들기 시작하면 옮기지 않고 `status`만 바꾼다
- `type: idea`, `status`: 아이디어, 진행 중, 보류(나중에 하기로 함), 접음, 완료
