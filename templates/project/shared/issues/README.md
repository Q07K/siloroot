# 이슈

겪은 문제 하나에 문서 하나: 무엇이 났고, 원인, 해결, 다시 안 나게 한 것.

## 여기에 넣는 것

- 깨졌거나 느렸던 일, 찾은 원인, 고친 것

## 여기에 넣지 않는 것

- 개념 설명 → 홈 공부 노트(이슈는 홈을 가리키지 않는다)
- 아이디어 문서나 작업 일지 안에 묻지 않는다

## 파일 이름과 상태

- 파일: `영문-증상.md`
- `type: issue`, `status`: 열림, 보류(지금은 안 고침, 기다리는 것 포함), 해결, 안 고침

## 쓰는 틀

```markdown
---
type: issue
status: 열림
created: YYYY-MM-DD
related: []
---

# 증상 한 줄

## 겪은 일

## 원인

## 해결

## 다시 안 나게

(보류면) 까닭, 무엇을 기다리나, 언제 다시 보나
```
