# 뷰어 댓글

이 작업 공간 문서에 뷰어에서 남긴 댓글. 뷰어가 만든다.

## 여기에 넣는 것

- 뷰어 댓글 창이 만든 파일

## 여기에 넣지 않는 것

- 글쓰기 규칙 후보, 사용자 정보 후보 → `home:feedback/`

## 파일 이름과 상태

- 파일: `YYYY-MM-DD-NNN.md`
- `type: feedback`, `status`: 대기, 진행 중, 완료, 안 함
