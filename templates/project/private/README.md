# 개인 영역

나만 보는 문서를 둔다. 이 폴더는 git에서 빠져 있다(`.git/info/exclude`).

| 자리 | 무엇이 있나 |
| --- | --- |
| `private/worklog/` | AI가 요청을 마칠 때마다 한 일을 한 줄로. 하루에 한 문서 (`log`) |
| `private/open-questions.md` | 사용자 확인이 필요한 것. 한 장 (`ledger`) |
| `private/sources/` | 받은 자료, 회의 메모처럼 다른 문서의 근거가 되는 원본 (`source`) |
| `private/notes/` | 개인 메모 (`note`) |
| `private/discussions/` | 사용자와 의견을 주고받은 논의 기록. 논의 하나에 하나 (`note`) |
| `private/feedback/` | 이 작업 공간 문서에 뷰어에서 남긴 댓글 (`feedback`) |

자리 폴더마다 `README.md`가 있다. 댓글 형식과 처리 절차는 홈의 `home:feedback/README.md`와 `/siloroot:feedback`을 따른다. 글쓰기 규칙 후보와 사용자 정보 후보는 여기가 아니라 홈 `feedback/`에 만든다.
