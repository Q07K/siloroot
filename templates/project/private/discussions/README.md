# 논의

사용자와 의견을 주고받은 기록. 논의 하나(관심사 하나)에 문서 하나.

## 여기에 넣는 것

- 누가 무슨 말을 했나, 무엇을 정하지 않았나

## 여기에 넣지 않는 것

- 정한 것 → 결정 기록이나 아이디어 문서(여기서는 가리키기만)
- 이야기 주제가 바뀌면 새 논의 기록을 연다

## 파일 이름과 상태

- 파일: `YYYY-MM-DD-주제.md`
- `type: note`, `status`: 사용 중, 보관
