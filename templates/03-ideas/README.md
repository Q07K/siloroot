# 아이디어

아직 만들지 않은 아이디어를 둔다. 아이디어 하나에 파일 하나(`영문-이름.md`), 맨 위 속성은 `type: idea`. 시안(html, 그림)이 있으면 옆에 두고 본문에서 링크한다.

| status | 뜻 |
| --- | --- |
| 아이디어 | 적어만 둠 |
| 진행 중 | 만들기 시작함 |
| 보류 | 잠시 멈춤 |
| 접음 | 하지 않기로 함. 이유를 본문에 남긴다 |
| 완료 | 다 만듦 |
