# 작업 일지

AI가 홈에서 요청 하나를 마칠 때마다 한 일을 한 줄로 적는다. 하루에 한 문서.

## 여기에 넣는 것

- 한 일과 그 결과 문서 경로 한 줄

## 여기에 넣지 않는 것

- 확인할 것 → `open-questions.md`

## 파일 이름과 상태

- 파일: `YYYY-MM-DD.md`. 그날이 지나면 고치지 않는다
- `type: log`, `status`: 사용 중(오늘), 끝남(지난 날)
