# 개인 아이디어

어느 프로젝트와도 상관없는 내 아이디어. 사용자가 "개인 아이디어", "홈에"처럼 말한 것만 둔다.

## 여기에 넣는 것

- 개인 아이디어 하나에 문서 하나. 프로젝트에서 나왔으면 제목 아래에 나온 프로젝트를 한 줄

## 여기에 넣지 않는 것

- 프로젝트에서 만들 것 → 그 프로젝트의 `shared/ideas/`(기본)

## 파일 이름과 상태

- 파일: `영문-이름.md`
- `type: idea`, `status`: 아이디어, 진행 중, 보류, 접음, 완료
