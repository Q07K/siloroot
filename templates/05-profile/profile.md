# 사용자 정보

AI가 일하면서 본 사용자의 작업 습관과 선호 가운데 사용자가 승인한 것만 모은다. `CLAUDE.md`가 이 파일을 불러와서 모든 대화에 쓰인다.

- 후보는 AI가 `04-feedback/trait-*.md`로 만들고, 사용자가 승인하면 여기에 한 줄로 옮긴다. 사용자가 "앞으로 항상"처럼 직접 말한 것은 그 말을 승인으로 보지만, 그때도 후보 파일을 먼저 만든다. 절차는 `/siloroot:feedback`의 D, E에 있다.
- 프로젝트 하나에만 해당하는 규칙은 그 프로젝트 문서에, 글 표현 규칙은 `writing-guide.md`에 둔다. 여기에는 사람에 대한 것만 둔다.
- 사용자가 직접 고치거나 지워도 된다. AI는 사용자가 고친 줄을 되돌리지 않는다.
