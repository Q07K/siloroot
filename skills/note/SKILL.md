# 문답으로 공부하기 (기본 방식)

사용자가 질문을 이어 가고, Claude는 답하면서 그 내용을 공부 노트로 남긴다. 폴더 이름은 `.siloroot/config.json`의 `dirs.study`(기본 `02-study`)를 따른다.

## 답하는 법

- 물은 만큼만 답한다. 한 번에 다 풀어 놓지 말고 다음 질문의 여지를 남긴다.
- 사용자가 쓰는 말에 맞춘다. 사용자가 부르는 이름(예: "라운드")과 정식 이름(예: `border-radius`)이 다르면 둘이 같다는 것부터 짚는다.
- 예시와 숫자를 하나씩 든다. 그림이 도움이 되면 `02-study/diagrams/주제-내용.svg`로 그리고 노트에 넣는다.

## 노트 남기기

1. 주제 하나에 파일 하나(`02-study/영문-주제.md`). 같은 주제를 다시 공부하면 같은 파일에 이어 적는다.
2. 새 노트는 `02-study/README.md`의 "노트 쓰는 법" 틀을 그대로 쓴다. `type: study`, `status: 검증 전`, `created`는 오늘.
3. "이해한 내용"에는 사용자가 이해한 것을 사용자의 말에 가깝게 정리한다. Claude의 설명을 통째로 옮기지 않는다.
4. 사용자가 헷갈려 한 곳은 "막혔던 곳"에 날짜와 함께 한 줄.
5. 이번에 다루지 못한 것, 사용자가 궁금해했지만 미룬 것은 "다음에 볼 것"에 적는다.
6. 새 주제면 `02-study/README.md` 주제 목록 맨 위에 한 줄을 더한다 (주제 링크, 처음 본 날, 이해도 `검증 전`).
7. 노트를 고칠 때마다 한 번에 저장한다. 뷰어가 바뀐 줄을 노랗게 보여 준다.

## 하지 않는 것

- 이해도(`status`)는 여기서 올리지 않는다. 이해도는 검증(`/siloroot:verify`)을 거쳐서만 바뀐다.
- 사용자가 "검증해 줘"라고 하면 이 방식을 멈추고 `/siloroot:verify`로 넘어간다.
