# 뷰어는 분할 화면에서도 쓸 수 있게 만든다

연결 그래프 옆 패널 시안을 고르던 중(2026-11-26), 사용자가 정함.

## 약속

- 뷰어는 PC에서 쓰는 웹 화면이지만 한 가지 창 크기만 가정하지 않음
  - 모니터 비율이 여러 가지임(16:9, 16:10, 울트라와이드, 세로 모니터)
  - 화면을 반으로 나누거나 2~4분할로 띄워 놓고 보는 사람이 있음
- 화면, 패널, 상자를 고칠 때 아래 크기에서 깨지지 않는지 봄

| 크기 | 어떤 화면 |
| --- | --- |
| 1920×1040 안팎 | FHD 전체 |
| 1280×720 | QHD 4분할 |
| 960×1040 | FHD 2분할(좌우 반) |
| 960×520 | FHD 4분할 |
| 640×1040 | FHD 3분할(세로로 셋) |

- 너비는 창이 아니라 그 요소가 들어간 그릇(그래프 판, 패널, 제목 줄)의 너비로 정함. 같은 문서 뷰가 문서 화면에도, 좁은 패널에도 들어가기 때문
  - 지금 문서 화면은 이미 그렇게 됨: 본문과 오른쪽 칸이 flex 줄바꿈이라 그릇이 좁으면 오른쪽 칸이 본문 아래로 내려감(`.doc`, `viewer/template.html`)
- 좁아서 다 못 넣을 때는 숨기지 않고 접음. 예: 흔적 흐름 → 개수 단추와 목록
- 웹 시안을 낼 때도 위 크기 가운데 걸리는 것을 함께 띄워 보임(`shared/conventions/web-mockup-real-screen.md`)
