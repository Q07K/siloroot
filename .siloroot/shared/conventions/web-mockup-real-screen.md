# 웹 시안은 실제 화면으로 보인다

홈 그래프의 바깥 프로젝트 표시 방법을 고르던 중(2026-11-26), 사용자가 정함.

## 약속

- 뷰어(웹) 화면 모양을 고르는 시안을 텍스트 스케치(글자 그림, 말로 그린 배치)로 주지 않음
- 실제로 열어 볼 수 있는 화면으로 줌
  - 뷰어 코드(`viewer/template.html`, `viewer/build.mjs`)를 복사해 안마다 고치고 로컬 서버로 띄움
  - 실제 작업 공간 데이터나, 그 모양을 따른 예시 데이터를 씀
  - 안이 여럿이면 안마다 따로 열어 견줄 수 있게 함
- AI가 브라우저로 먼저 열어 보고 확인한 뒤 주소와 스크린샷을 건넴
- 안의 장단을 견주는 표는 써도 됨. 모양을 고르게 할 때는 화면을 함께 줌
- 움직임이 핵심인 시안은 gif로 남겨도 됨

## 시안 파일 자리

- 작업 중 복사본: 저장소 밖 임시 폴더. 작업 브랜치를 건드리지 않음
- 고른 시안을 남길 때: 그 아이디어 문서 옆(`shared/ideas/`)에 두고 본문에서 링크
