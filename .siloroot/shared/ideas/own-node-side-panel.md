# 내 노드도 옆 패널로 열기

`shared/ideas/cross-workspace-jump.md`의 옆 패널을 0.8.6에서 써 본 뒤 사용자가 냄(2026-11-26).

## 사용자가 낸 것

- 프로젝트 뷰어에서 홈 노드는 옆 패널로 열리는데, 프로젝트 노드는 눌러도 옆 패널로 안 열림
- 내 노드도 옆 패널로 열리면 좋겠음
- 지금 아쉬운 점: 노드를 누르면 작은 정보 상자(들어옴, 나감, 수정, 연결된 문서)가 뜨고, 그래프에는 그 노드와 연결이 강조된 채 고정됨("활성화 고정")
- 패널로 바꿀 때 이 둘을 어떻게 살릴지 고민이 필요함

## 지금 동작(0.8.6)

| 누른 노드 | 뜨는 것 | 그래프 강조 |
| --- | --- | --- |
| 내 노드(shared, private) | 정보 상자(`select`) | 고정됨(`GS.sel`) |
| 바깥 노드(홈, 다른 프로젝트) | 옆 패널(`openXPanel`) | 고정 안 됨. `pick`이 `select(null)`로 고른 노드를 비움 |

- 설계대로의 동작임: `shared/design/home-graph-and-workspace-jump.md` "내 점을 누르면 옆 패널을 닫고 지금 정보 상자"

## 시안(실제 화면, 2026-11-26)

- 지금 빌드된 프로젝트 뷰어를 복사해 노드 누르기만 바꿈. 로컬 4197의 `/a`, `/b`, `/c`
- 세 안 공통
  - 내 노드도 옆 패널로 엶
  - 패널이 열린 동안 누른 노드와 이웃을 강조한 채 둠. 바깥 노드도 같음
  - 다른 노드나 패널 안 연결된 문서를 누르면 패널 내용과 강조가 함께 바뀜
  - X, Esc, 그래프 빈 곳 누르기로 패널과 강조를 함께 닫음
  - 바닥 단추는 "문서 열기"(바깥 노드는 지금처럼 "<작업 공간> 뷰어에서 열기")

| 안 | 정보 상자 내용을 둔 곳 |
| --- | --- |
| A 정보 먼저 | 본문 위에 들어옴, 나감, 수정 세 칸과 연결된 문서 목록 |
| B 본문 먼저 | 머리에 한 줄(들어옴, 나감, 수정), 본문 아래에 연결된 문서 |
| C 탭 | 머리에 한 줄, "본문"과 "연결된 문서 N" 탭 |

## 시안에서 보인 것

- 패널이 오른쪽 private 영토를 덮음. 그쪽 이웃 노드는 강조돼도 패널 뒤에 숨음
- "이번 답에서 거쳐 간 문서" 상자(흔적)가 오른쪽 아래에 있어 패널과 겹침

## AI가 정함(시안에 넣은 것, 사용자가 바꿀 수 있음)

- 패널이 열린 동안 누른 노드와 이웃 강조를 고정함. 바깥 노드도 같음
- X, Esc, 그래프 빈 곳 누르기로 패널과 강조를 함께 닫음
- 고른 탭은 다른 노드를 눌러도 그대로 둠
- 바닥 단추: 내 노드는 "문서 열기", 바깥 노드는 지금처럼 "<작업 공간> 뷰어에서 열기"

## 덮인 이웃과 흔적 상자 시안(2026-11-26)

- C안 위에 둘을 더함. 로컬 4197의 `/d`, `/e`
- 둘 다 그래프 옮기기
  - 노드를 누른 뒤 그 노드와 이웃이 빈 곳에 다 보이지 않을 때만 그래프를 옮김
  - 빈 곳: 패널 왼쪽에서 범례, 필터 상자, 흔적 상자를 피한 자리
  - 다 들어가지 않으면 줄임. 키우지는 않음
  - 0.36초 동안 부드럽게 옮기고, 끝난 뒤 한 번 더 맞춤

| 안 | 흔적 상자 |
| --- | --- |
| D | 패널 왼쪽으로 비킴. 패널 너비를 바꾸면 따라 움직임 |
| E | 패널이 열린 동안 숨김. 닫으면 다시 보임 |

- 확인: "영토가 끊어지거나 찢어진다" 노드를 누르면 이웃 6개가 모두 패널, 범례, 흔적 상자 밖에 보임(1440×900, 77%로 줄어듦)

## 흔적을 머리 줄로 옮기는 시안(2026-11-26)

- 사용자: 흔적 흐름을 "연결" 제목 줄(필터, 흔적, 맞춤이 있는 줄)에 넣으면 이상할까
- E 위에 둘을 더함. 로컬 4197의 `/f`, `/g`. 흔적 상자는 없앰

| 안 | 흔적 |
| --- | --- |
| F | 제목 줄 가운데에 번호 칩이 흐름으로 이어짐(› 로 잇고, 가장 최근 칩 강조). 넘치면 앞쪽이 흐려지며 가로로 밀림. 칩을 누르면 그 노드를 누른 것과 같음 |
| G | 흔적 단추에 개수 배지와 ▾. 누르면 단추 아래에 지금 흔적 상자 목록이 펼쳐짐(패널 위에 뜸). 바깥을 누르면 접힘 |

- 확인: F는 패널이 열려도 흔적이 제목 줄에 그대로 보임. 칩 "로드맵"을 누르면 패널이 로드맵으로 바뀜. 제목 줄은 한 줄로 유지됨
- G에서 흔적 켜고 끄기를 어디 둘지는 시안에서 정하지 않음

## 분할 화면에서 본 것과 시안 H(2026-11-26)

- 사용자: PC 웹 화면이지만 모니터 비율이 여러 가지이고, 화면을 반으로 나누거나 2~4분할로 보는 사람이 있을 것. 반응형이어야 함 → `shared/conventions/viewer-responsive.md`
- F를 분할 크기로 열어 봄
  - FHD 2분할(960×1040): 패널이 그래프 판(669px)의 70~80%를 덮음
  - FHD 4분할(960×520): 패널 뒤로 그래프가 거의 안 보이고, 본문도 서너 줄
  - FHD 3분할(640×1040): 제목 줄의 흔적 흐름에 칩이 한두 개만 보임. G의 단추 목록은 그대로 잘 보임
- 시안 H(로컬 4197의 `/h`): 넓으면 F, 좁으면 G. 패널은 그래프 판 크기에 따라 자리를 바꿈

| 판 크기 | 패널 | 흔적 | 확인한 크기 |
| --- | --- | --- | --- |
| 패널 옆에 그래프가 360px 이상 남음 | 오른쪽 | 흐름(F) | 1280×720 |
| 아니고 판 높이 640px 이상 | 아래 58% | 자리 있으면 흐름, 없으면 단추 목록 | 960×1040(흐름), 640×1040(단추) |
| 둘 다 아님 | 판 전체 | 흐름 | 960×520 |

- 아래 패널일 때 그래프 옮기기는 패널 위 빈 곳에 맞춤. 640×1040에서 누른 노드와 이웃이 위쪽에 모임
- 960×520처럼 판이 아주 낮으면 판 전체 패널에도 본문이 서너 줄만 보임. 사용자가 H를 그대로 골라서 이때도 판 전체 패널로 둠

## 시안 J: 흔적 상자를 단추 아래로(2026-11-26)

- 사용자: 흔적은 G가 좋다 → 이어서 "화살표나 숫자는 넣지 말고, 버튼을 누르면 기존 구성이 저 위치에서 보이도록"
- 로컬 4197의 `/j`. H의 패널 자리 규칙 위에, 지금 흔적 상자를 오른쪽 아래에서 흔적 단추 바로 아래로 옮김
- 흔적 단추는 지금처럼 켜고 끄기(그래프 위 흔적 선, 번호, 상자를 함께)

| 패널 | 흔적 상자 |
| --- | --- |
| 닫힘 | 흔적 단추 바로 아래 |
| 오른쪽 | 패널 왼쪽 위로 비킴 |
| 아래 | 시안에서는 단추 아래 그대로 두었더니 위쪽 그래프 자리의 절반 넘게 가림(960×1040, 640×1040). 사용자가 패널이 열린 동안 숨기기로 정함 |
| 판 전체 | 패널이 열린 동안 숨김 |

## 방향 바뀜(2026-11-26)

- 사용자가 근본 해결을 정함: 문서 화면과 옆 패널을 한 문서 뷰로 통일하고, 문서 화면이 그대로 패널에 보이게 함
  - 결정: `shared/decisions/unify-doc-view.md`
  - 이어서 하는 일: `shared/requirements/unified-doc-view.md`
- 그래서 패널 전용 모양(C안 머리와 탭)은 따로 만들지 않음. 문서 뷰 디자인 개선에서 다시 봄
- 아직 쓸 것: 패널이 열린 동안 강조 고정, 덮인 이웃 옮기기(D, E), 흔적 상자 처리
