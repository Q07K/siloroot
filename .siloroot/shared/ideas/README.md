# 아이디어

아이디어와 만들기 시작한 프로젝트를 둔다. 아이디어 하나에 파일 하나(`영문-이름.md`), 맨 위 속성은 `type: idea`. 시안(html, 그림)이 있으면 옆에 두고 본문에서 링크한다.

만들기 시작하면 파일을 옮기지 않고 `status`만 `진행 중`으로 바꾼다. 그때 로드맵 "지금" 칸에 올리고 `shared/requirements/`에 요구사항 문서를 만든다. 결정은 `shared/decisions/`, 설계는 `shared/design/`, 구현 계획은 `shared/plans/`에 두고 이 문서의 `related`에서 가리킨다. 이 폴더에는 아이디어만 둔다. 공부나 다른 아이디어에서 나온 아이디어면 제목 아래에 어디서 나왔는지 한 줄 적는다.

| status | 뜻 |
| --- | --- |
| 아이디어 | 적어만 둠 |
| 진행 중 | 만들기 시작함 |
| 보류 | 잠시 멈춤 |
| 접음 | 하지 않기로 함. 이유를 본문에 남긴다 |
| 완료 | 다 만듦 |
