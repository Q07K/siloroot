# 세션을 시작할 때 컨벤션을 맥락에 넣기

좁은 문서 뷰 시안을 만들다가 AI가 컨벤션을 다 읽지 않고 시작한 일에서 나옴(2026-11-27).

## 왜

- 컨벤션 README에 "일을 시작하기 전에 이 폴더의 문서를 모두 읽는다"고 적혀 있어도 AI가 일부만 읽고 시작함
- 2026-11-26, 2026-11-27 두 번 사용자가 지적함
- AI 메모리로 막으려 했지만 다시 일어남
- 사용자: "SiloRoot 플러그인에 컨벤션 문서를 클로드 코드가 채팅 세션 시작할때 무조건 필수로 읽도록 훅같은거 걸 수 있나?"

## 생각한 방법(AI 제안)

- 세션 시작 훅(SessionStart)이 컨벤션 폴더의 문서 내용을 그대로 맥락에 넣음
  - "읽어라"라는 지시가 아니라 내용이 처음부터 맥락에 있음. AI가 읽기를 빼먹을 수 없음
  - 지금 세션 시작 훅(`viewer/notify.mjs --session`)이 이미 같은 길(`additionalContext`)로 할 일을 알림
  - 세션 시작 훅은 새로 시작, 이어 열기, 비우기, 맥락 압축 뒤에도 돎. 압축 뒤에도 다시 들어감
- 맥락에 넣는 길이에 제한이 있음(약 10,000자). 지금 컨벤션은 5개, 약 2,500자라 들어감
  - 넘으면 목록과 경로만 넣고 "모두 읽고 시작"으로 바꾸는 식의 대안이 필요함
- 버린 것: 관리 블록에서 `@` 가져오기. 파일 이름을 하나씩 적어야 해서 새 컨벤션이 저절로 들어가지 않음
