# 새 점과 새 선을 다음 메시지까지 남기기

연결 그래프의 흔적(`shared/ideas/live-reading-graph.md`)을 쓰다가 사용자가 제안함.

## 왜

- 지금은 새로 생긴 점과 선이 잠깐 나타났다가 사라짐(선 강조 6초, 모두 8초 뒤 걷음)
- 사용자: 흔적처럼 다음 메시지를 보내기 전까지 남기고 싶음
- 사용자: 그러면 흔적과 겹쳐 헷갈리지 않을지 걱정

## 겹침

| | 지금 새 점·새 선 | 흔적 |
| --- | --- | --- |
| 선 | 강조색(`--accent`), 굵기 2 | 읽음 `--accent`, 고침 `--flash-bar`, 굵기 2 |
| 점 | 둘레가 퍼짐, 이름 굵게 | 고리, 번호, 이름 굵게 |

- 새 선 강조가 흔적 읽음 선과 색, 굵기가 같음. 남기면 가를 수 없음
- 그래서 새 표시는 흔적과 다른 수단을 씀
- Claude가 읽던 문서에 잇는 새 문서를 만들면 그 새 선은 대부분 흔적이 위에서 덮음. 새 표시로 보이는 건 흔적이 지나가지 않은 새 선

## 시안

- 뷰어 복사본과 작업 공간 복사본(문서 146개)으로 띄워 봄
- 밝은 화면: [mockup-light.jpg](persistent-new-marks/mockup-light.jpg)
- 어두운 화면: [mockup-dark.png](persistent-new-marks/mockup-dark.png)

| 부분 | 시안 |
| --- | --- |
| 기준 | 흔적을 비울 때(다음 메시지)의 점과 선 목록. 그 뒤에 생긴 것이 새 것 |
| 새 선 | 그어지는 움직임부터 새 색. 확대와 관계없이 화면에서 2.6px, 같은 색으로 은은히 번짐 |
| 새 점 | 둘레를 새 색으로 칠함. 점 오른쪽 아래에 "새" 꼬리표. 꼬리표는 이름과 따로 늘 보이고 화면에서 같은 크기 |
| 흔적 목록 | 새 문서 줄에 "새". 머리에 "새 문서 N, 새 연결 M" |
| 걷기 | 흔적이 비워질 때 함께 걷음. 알림 "흔적과 새 표시를 비웠어요" |
| 이름 | 새 점, 흔적 점 이름을 억지로 켜지 않고 이름 배치(`labelPlan`) 안에서 앞 순위로만 둠 |

- 이름을 억지로 켜면 같은 곳에 모인 새 점들의 이름이 겹침. 배치 안으로 넣자 보이는 이름 12개 중 겹침 0개

## 아직 안 정한 것

만들기 시작함(2026-11-27, 사용자 "지금 만들어 줘"). 아래는 AI가 기본값으로 만들고 사용자 확인을 기다림(`shared/requirements/persistent-new-marks.md`).

- 흔적 점 이름도 이름 배치 안으로 넣을지: 넣음
- 새 표시 세기: 시안 그대로(흔적보다 먼저 눈에 띔)
- 흔적 단추를 끄면 새 표시도 함께 끌지: 끄지 않음
- 사용자가 직접 만든 문서, 다른 세션이 만든 문서도 같은 기준으로 남길지: 남김

## 만들 때 볼 것

- 기준을 서버에 둠: 흔적을 비울 때(`resetTrail`, `lib/trail.mjs`) 그때의 점과 선 목록을 남김. 시안은 탭의 sessionStorage에 두어 새 탭을 열면 그때를 기준으로 삼음
- 추가 색 꼬리표는 밝은 화면에서 흔적 읽음 번호(짙은 회청색)와 비슷해 보임. 모양(둥근 꼬리표, 오른쪽 아래)으로 가르는지 실제 화면에서 다시 봄
- 같은 문서를 여러 번 거치면 흔적 번호표가 "2·5·8"처럼 넓어져 이웃 점을 가림(지금 코드에도 있음)
- 바뀌는 곳: `viewer/template.html`의 실시간 갱신(`born`, `fresh`), 이름 배치(`labelPlan`), 흔적 목록(`trailList`)
