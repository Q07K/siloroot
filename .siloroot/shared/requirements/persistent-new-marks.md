# 새 점과 새 선을 다음 메시지까지 남기기

## 문제

- 연결 그래프에 새로 생긴 점과 선이 잠깐(선 강조 6초, 모두 8초) 보였다 사라짐
- Claude가 한 답에서 무엇을 새로 만들었는지 다음 메시지 전까지 볼 수 없음
- 그대로 오래 남기면 새 선 강조가 흔적 읽음 선과 색, 굵기가 같아 헷갈림

## 목표와 비목표

- 목표
  - 지난 메시지 뒤로 새로 생긴 점과 선을 다음 메시지까지 남김
  - 흔적과 다른 수단(뷰어의 추가 색, 굵기와 번짐, "새" 꼬리표)으로 보여 겹쳐도 가를 수 있음
  - 새로 고침, 필터 바꾸기에도 그대로
  - 흔적 점과 새 점의 이름이 서로 겹치지 않음
- 비목표
  - 고친 문서 표시(흔적의 "고침"이 맡음)
  - 지운 문서를 다음 메시지까지 남기기(지금처럼 1초 흐려짐)
- 성공 기준
  - 새 메시지 → 새 문서 생성 → 8초 넘게 지나도, 새로 고쳐도 표시 남음
  - 다음 메시지에 표시가 걷힘. 흔적이 빈 채로 온 메시지에도
  - 보관 문서 필터를 바꿔 다시 보인 문서는 새 것으로 치지 않음

## 만든 방법

- 새 메시지 표: 흔적 비우기 훅(`resetTrail`, `lib/trail.mjs`)이 메시지마다 `state/trail/turn.json`에 `{ session, at }`을 씀. 세션 흔적 파일이 없어도 씀
- 기준: 뷰어 서버가 흔적 폴더 감시로 표가 바뀐 것을 보면 그 자리에서 빌드함. 빌드(`turnNew`)가 표가 바뀐 뒤 처음 본 점과 선을 `state/turn-base.json`에 기준으로 남김
- 새 것: 빌드가 기준에 없는 점(문서 경로, 바깥 문서는 `@` + 대상)과 선(두 끝을 정렬해 `|`로 이음)을 `data.turn`에 실음. 원래 데이터로 견주어 필터와 상관없음
- 화면: 그래프가 `D.turn`으로 새 점(`nw`)과 새 선을 고름. 새 메시지 시각이 바뀌면 화면 표시를 바로 비움(`turnMarks`)
- 이름: 흔적 점과 새 점 이름을 억지로 켜지 않고 이름 배치(`labelPlan`) 앞 순위로 둠. 150%보다 작을 때도 이름끼리 겹치지 않으면 보임

## AI가 정한 것(사용자 확인 전)

- 흔적 점 이름도 이름 배치 안으로 넣음(시안과 같음)
- 세기: 시안과 같음(선 2.6px, 번짐 2.5px, 둘레 불투명도 .45)
- 흔적 단추를 꺼도 새 표시는 남김
- 사용자가 직접 만든 문서, 다른 세션이 만든 문서도 같은 기준으로 셈
- 새 선이 60개를 넘으면 번짐을 끔(SVG 그림자가 무거움)

## 결과

- 0.8.11로 내보냄(PR #52). 뷰어 복사본(문서 146개)에서 실제 훅으로 확인
  - 새 문서 2개, 새 연결 5개가 10초 넘게, 새로 고쳐도 남음. 보관 문서 필터를 바꿔도 2개, 5개 그대로
  - 다음 메시지에 0개로 걷히고 알림 "흔적과 새 표시를 비웠어요". 흔적이 빈 채로 온 메시지에도 걷힘
  - 새 문서 30개, 새 연결 90개에서 번짐이 꺼짐. 속도는 브라우저 창이 숨겨져 재지 못함
- 남은 것: 메시지를 보낼 때 뷰어 서버가 꺼져 있었으면 서버가 켜진 뒤 처음 그린 모습부터 셈
