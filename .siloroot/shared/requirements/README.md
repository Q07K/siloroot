# 요구사항

기능 하나에 문서 하나. 그 기능이 어떤 문제를 왜, 어떻게 풀었는지 모으는 중심 문서다. 세부는 각 자리 문서에 두고 여기서는 경로로 가리킨다.

## 여기에 넣는 것

- 아이디어를 만들기 시작할 때(로드맵 "지금" 칸에 올릴 때) 만든다
- 문제, 목표와 비목표, 거쳐 온 길(아이디어, 결정, 설계, 구현 계획, 이슈 경로), 결과(무엇이 바뀌었나, 숫자)

## 여기에 넣지 않는 것

- 흩어진 생각 → `shared/ideas/`
- 결정 하나하나의 까닭 → `shared/decisions/`
- 구현 단계 → `shared/plans/`

## 파일 이름과 상태

- 파일: `영문-기능.md`
- `type: requirement`, `status`: 시작 전, 진행 중, 완료, 접음

## 쓰는 틀

type: requirement
