# 설계

기능을 어떻게 만들지. 쓴 때의 설계라 검토가 끝나면 고정하고, 크게 바뀌면 새로 쓴다.

## 여기에 넣는 것

- 만드는 방법, 견준 대안과 고른 까닭, 바꾸는 곳

## 여기에 넣지 않는 것

- 지금 전체 구조 → `shared/architecture.md`
- 구현 단계 체크 목록 → `shared/plans/`
- 용어 표 → `shared/conventions/glossary.md`

## 파일 이름과 상태

- 파일: `영문-기능.md`
- `type: design`, `status`: 제안, 확정, 바뀜
