# 한 문서 뷰: 문서 화면과 옆 패널을 같은 구현으로

`shared/requirements/unified-doc-view.md`의 1단계(통일) 설계. 2단계(문서 뷰 디자인 개선)는 통일이 끝난 뒤 실제 화면 시안으로 따로 설계함.

## 의도

- 같은 문서를 문서 화면과 연결 그래프 옆 패널에서 따로 그리지 않음
- 문서 화면의 뷰가 그대로 패널에 보임. 문서 뷰를 고치면 두 곳이 함께 바뀜
- 그래야 2단계 디자인 개선을 한 곳에서만 함
- 결정: `shared/decisions/unify-doc-view.md`. 컨벤션: `shared/conventions/reuse-existing-implementation.md`

## 목표, 비목표, 실패로 볼 것

- 목표
  - 문서 뷰를 그리는 구현이 하나. 문서 화면과 옆 패널이 같은 함수를 부름
  - 연결 그래프에서 노드(내 노드, 바깥 노드)를 누르면 옆 패널에 그 문서 뷰가 열림
  - 프로젝트 뷰어와 홈 뷰어 모두
- 비목표
  - 문서 뷰 디자인 개선(2단계)
  - 옆 패널에서 다른 작업 공간 문서 고치기, 댓글(`shared/design/home-graph-and-workspace-jump.md`의 비목표 유지)
  - 다른 작업 공간 문서의 연결 정보(그쪽에서 가리키는 문서 등)를 새로 싣기
- 실패로 볼 것
  - 문서 화면과 패널에 문서를 그리는 코드가 따로 남음
  - 패널에서 저장하거나 댓글을 남기면 그래프 배치, 확대, 패널이 날아감
  - 문서 화면의 지금 동작(편집, 댓글, 목차, 실시간 반영)이 깨짐

## 견준 방법

| 방법 | 내용 | 결과 |
| --- | --- | --- |
| 1. 함수 하나 | `viewDoc`이 `#view`에 직접 쓰던 것을 "받은 자리에 문서 뷰를 그리는 함수"로 바꿈. 문서 화면과 패널이 같이 부름 | 고름(사용자, 2026-11-26) |
| 2. iframe | 패널에 문서 화면 주소를 그대로 띄움 | 버림. 열 때마다 뷰어 전체(약 3.8MB)를 다시 읽고, 그래프 강조·패널 상태를 주고받기 어려움 |
| 3. 나란히 | 그래프와 문서 화면을 한 화면에 반씩 | 버림. 화면 이동 구조를 크게 바꿔야 하고, 결국 1번의 뷰 나누기가 먼저 필요함 |

## 만드는 법

### 문서 뷰 함수

- 지금 `viewDoc(p)`(`viewer/template.html`)가 만드는 HTML을 그대로 받은 그릇(host)에 그리는 함수로 바꿈
  - 문서 화면: `viewDoc(p)`는 `#view`를 그릇으로 넘겨 이 함수를 부름
  - 옆 패널: 패널 몸통을 그릇으로 넘겨 같은 함수를 부름
- 그리는 것은 지금 문서 화면과 같음: 경로와 수정 시각, 편집·댓글 도구, 속성 칩, 본문, 오른쪽 칸(댓글 남기기, 이 문서의 피드백, 가리키는 문서, 가리키는 문서, 목차)
- `wireDocTools`와 목차 연결은 `document` 전체가 아니라 그릇 안에서 요소를 찾게 바꿈(지금은 `$('#art')`, `$('#csend')` 같은 전역 id)
- 모드를 받음: 문서 화면(page)과 패널(panel). 모드에 따라 다른 것은 아래 "패널에서 다른 것"뿐

### 좁은 그릇

- 패널은 좁음(처음 440px, 최소 320px). 그릇이 좁으면 오른쪽 칸(`.side`)이 본문 아래로 내려감
- 문서 화면도 창이 좁으면 같은 규칙을 따름. 화면 너비가 아니라 그릇 너비로 정함
- 지금 `.doc`이 이미 그럼: 본문(`flex:999 1 600px`)과 오른쪽 칸(`flex:1 1 280px`)이 flex 줄바꿈이라 그릇이 약 900px보다 좁으면 오른쪽 칸이 내려감. FHD 2분할 문서 화면에서 확인함. 패널에서도 이 규칙을 그대로 씀

### 옆 패널

- 패널 틀(위치, 덮기, 너비 손잡이, 너비 기억, Esc와 X로 닫기)은 0.8.6 `openXPanel` 그대로 씀
- 패널 머리에는 닫기와 화면 이동 단추만 둠. 제목, 경로, 속성은 문서 뷰가 그림
  - 내 노드: "문서 화면으로" → `#doc/<경로>`
  - 바깥 노드: "<작업 공간> 뷰어에서 열기" → 지금 `openExternal`
- 0.8.6 패널이 따로 그리던 제목, 작업 공간 표시, 본문, "가리키는 내 문서 N개"는 문서 뷰로 옮김(아래 "바깥 노드")

### 노드 누르기

- 내 노드, 바깥 노드 모두 옆 패널에 문서 뷰를 엶
- 정보 상자(`#ginfo`, `select`)는 없앰. 정보 상자에 있던 것은 문서 뷰가 맡음
  - 들어옴, 나감, 연결된 문서 → 오른쪽 칸 "이 문서를 가리키는 문서", "이 문서가 가리키는 문서"
  - 수정 → 경로 줄의 수정 시각
  - "문서 열기" → 패널 머리 "문서 화면으로"
- 패널이 열린 동안 누른 노드와 이웃 강조를 고정함(`GS.sel`). 바깥 노드도 같음
- 다른 노드를 누르면 패널 내용과 강조가 함께 바뀜
- X, Esc, 그래프 빈 곳 누르기로 패널과 강조를 함께 닫음
- 흔적 상자의 줄을 누르면 지금처럼 그 노드를 누른 것과 같음(이제 패널이 열림)
- 노드 두 번 누르기로 문서 화면에 가는 것은 그대로

### 패널 안 링크

- 패널 안 문서 링크(본문 링크, 속성 `related`, 오른쪽 칸 목록)를 누르면 화면을 옮기지 않고 그 문서를 패널에 엶
  - 그래프에 보이는 노드면 강조도 그 노드로 옮김
  - 필터로 숨긴 문서면 패널만 바뀜
- 다른 작업 공간 링크는 지금 동작 그대로

### 패널 상태와 그래프에 안 보이는 문서(AI가 정함, 빌더 점검에서 나옴)

- 패널 상태는 노드 번호가 아니라 문서 경로로 둠. 강조(`GS.sel`)는 그 경로가 그래프에 보일 때만 그 노드에 둠
- 패널에 연 문서가 그래프에 안 보이면(필터로 숨김, 그래프에 없는 문서) 강조를 비움. 패널 내용과 강조가 다른 문서를 가리키지 않게 함
- 폴더를 꺼서 패널 문서가 숨으면 패널은 그대로 두고 강조만 비움(지금은 패널을 닫음). 다시 켜면 강조를 되살림
- 배치를 다시 짜도(`relayout`) 패널은 그대로 두고, 보이면 강조를 다시 둠(지금은 고른 노드를 비움)
- 흔적 줄이 그래프에 안 보이는 문서를 가리키면 문서 화면으로 가지 않고 패널에 엶

### 패널에서 편집, 댓글

- 문서 화면은 저장, 댓글, 취소 뒤 지금처럼 페이지를 새로 고침
- 패널에서는 새로 고치지 않음. 그래프 배치와 패널이 날아가서임
  - 저장, 댓글 뒤 최신 데이터를 받아(그래프 실시간 반영과 같은 길) 그래프와 패널 문서 뷰를 다시 그림
  - 취소는 패널 문서 뷰만 다시 그림
- 편집 중에는 실시간 반영이 끼어들지 않음(지금 `busy()`)
- 쓰던 내용 지키기(AI가 정함, 빌더 점검에서 나옴)
  - 패널에서 본문을 고치는 중이거나 댓글 칸에 글이 있으면, 패널을 닫거나 다른 문서로 바꾸기 전에 "쓰던 내용이 사라집니다"로 확인함. 다른 노드 누르기, 빈 곳 누르기, 흔적 줄, 패널 안 링크, "문서 화면으로", X 모두
  - 입력칸에 초점이 있을 때 Esc는 패널을 닫지 않음(지금은 `document` 전체에서 닫음)
  - 그래프 화면에서 쓰는 중에 파일이 바뀌면 "새로 고침" 알림을 띄우지 않고, 끌기 중처럼(`graphWaiting`) 반영을 미뤘다가 쓰기가 끝나면 반영함. 지금 알림의 새로 고침은 그래프와 패널을 날림

### 바깥 노드

- 같은 문서 뷰 함수에 바깥 문서를 넘김. 지금 빌드가 싣는 것: 제목(`extTitles`), 본문(`extTexts`)
- 있는 것만 그림
  - 경로 줄: 작업 공간 이름과 그 작업 공간 기준 경로
  - 속성 칩: 본문 맨 위 속성을 읽어 보임(빌드에서 읽든 화면에서 읽든 빌더)
  - 본문
  - "이 문서를 가리키는 문서": 이 작업 공간에서 그 문서를 가리키는 문서(0.8.6의 "가리키는 내 문서 N개")
- 그리지 않음: 편집, 댓글, 피드백 칸, "이 문서가 가리키는 문서", 수정 시각(싣지 않음)
- 본문을 못 읽었으면 지금처럼 "본문을 읽지 못했습니다."

### 실시간 반영

- 패널에 연 문서가 바뀌면 패널 문서 뷰도 다시 그림. 문서가 사라지면 패널을 닫음
- 지금은 그래프를 다시 그릴 때 바깥 노드 패널만 다시 열고 내 노드면 닫음(`viewGraph`의 `XP.id` 처리). 내 노드도 다시 열게 바꿈

### 덮인 이웃과 흔적 상자

- 패널이 오른쪽 이웃 노드와 흔적 상자를 덮는 문제
- 시안 D, E, F, G, H: `shared/ideas/own-node-side-panel.md`
- 흔적 상자는 흔적 단추 아래로 옮김(아래 "흔적")
- 그래프 옮기기: 누른 노드와 이웃이 빈 곳(패널을 뺀 자리에서 범례, 필터 상자를 피한 곳)에 다 보이지 않을 때만 옮기고, 필요하면 줄임
- 패널 자리는 아래 "좁은 화면"을 따름(시안 H)

### 좁은 화면(시안 H)

- 사용자가 시안 H의 패널 자리 규칙으로 정함(2026-11-26). 흔적은 뒤에 따로 정함(아래 "흔적"). 고른 화면: `shared/ideas/own-node-side-panel-mockup-h-960x1040.jpg`(이 화면의 제목 줄 흐름은 버림), `shared/ideas/own-node-side-panel-mockup-h-640x1040.jpg`
- 뷰어는 분할 화면에서도 씀: `shared/conventions/viewer-responsive.md`
- 0.8.6처럼 패널을 늘 오른쪽에 두면 FHD 2분할(960)에서 그래프 판의 70~80%를 덮고, 4분할(960×520)에서는 그래프가 거의 안 보임. 흔적 흐름(F)은 3분할(640)에서 칩 한두 개만 보임
- 패널 자리는 그래프 판 크기로 정함
  - 패널 옆에 그래프가 360px 이상 남으면 오른쪽(지금처럼). 패널을 가장 좁게(320px) 했을 때로 판정함(판 너비 680px 이상). 오른쪽일 때 보이는 너비는 저장한 너비와 "판 너비 - 360" 가운데 작은 것. 패널을 넓혀도 자리가 바뀌지 않게 하려는 것(최종 검토에서 나옴, AI가 정함)
  - 아니고 판 높이가 640px 이상이면 아래. 판 아래 58%를 패널, 위를 그래프로 쓰고 그래프 옮기기는 위쪽 빈 곳에 맞춤
  - 둘 다 아니면 판 전체를 덮음
  - 아래와 판 전체에서는 너비 손잡이를 숨김
- 확인한 크기(시안 H): 1280×720 오른쪽, 960×1040 아래, 640×1040 아래, 960×520 판 전체
- 기준 값(360, 640px)은 빌더가 다듬음

### 흔적(시안 J)

- 사용자가 정함(2026-11-26): 흔적 단추에 화살표나 숫자를 달지 않음. 단추를 누르면 지금 흔적 상자가 그대로 단추 아래에 보임
- 흔적 단추는 지금처럼 흔적 켜고 끄기. 켜면 그래프 위 흔적 선과 번호, 흔적 상자가 함께 보이고, 끄면 함께 사라짐. 켠 상태를 기억하는 것도 지금처럼(`GS.trail`)
- 흔적 상자 내용과 동작(번호, 읽음·고침, 문서 이름, 줄 누르기)은 지금 그대로. 바뀌는 것은 자리뿐
  - 패널이 닫혔을 때: 그래프 판 오른쪽 위, 흔적 단추 바로 아래(지금은 오른쪽 아래)
  - 패널이 오른쪽에 열리면: 패널 왼쪽 위로 비킴. 패널 너비를 바꾸면 따라 움직임(AI가 정함)
  - 패널이 아래에 열리면: 패널이 열린 동안 숨기고 닫으면 다시 보임(사용자). 위쪽 그래프 자리가 낮아서 상자가 그 절반 넘게 가렸기 때문(시안 J, 960×1040, 640×1040)
  - 패널이 판 전체를 덮으면: 아래와 같이 숨김(AI가 정함)
  - 숨긴 동안에도 흔적 단추는 켜진 채이고 그래프 위 흔적 선과 번호는 보임. 상자만 숨김
- 시안 G(배지, ▾, 바깥 누르면 접히는 목록)는 쓰지 않음

## 바꾸는 곳

- `viewer/template.html`
  - `viewDoc`, `wireDocTools`, 목차 연결: 그릇을 받는 문서 뷰 함수로
  - Esc 처리, 실시간 반영의 `busy()` 처리, 폴더 끄기·`relayout`·흔적 줄의 패널 처리
  - `openXPanel`, `closeXPanel`: 문서 뷰를 담는 패널 틀로
  - `viewGraph` 안 `pick`, `select`, 정보 상자 HTML과 CSS, `placeTrailBox`의 정보 상자 처리, `fitView` 장애물 목록의 `#ginfo`, 다시 그릴 때 패널 다시 열기
  - 문서 뷰 CSS: 그릇 너비 규칙
  - 흔적: 흔적 상자(`#gtrailbox`, `placeTrailBox`)의 자리를 흔적 단추 아래로. 패널 자리에 따라 비키거나 숨김
  - 패널 자리: 그래프 판 크기로 오른쪽, 아래, 판 전체를 고르고, 그래프 옮기기(`fitView`의 빈 곳 계산)를 패널 자리에 맞춤
- `viewer/build.mjs`: 바깥 문서 속성을 빌드에서 읽기로 하면
