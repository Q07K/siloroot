# 홈 그래프 영토와 작업 공간 오가기 설계

`shared/ideas/home-graph-projects.md`(A′)와 `shared/ideas/cross-workspace-jump.md`(옆 패널)에서 정한 것을 만드는 설계. 시안은 두 아이디어 옆의 그림.

## 왜

- 홈 뷰어 연결 그래프가 프로젝트용 코드를 그대로 써서, 홈 폴더가 회색 "other"로, 홈 맨 위 문서가 `private / .siloroot`로 잘못 보임
- 다른 작업 공간 문서를 보려면 지금은 점을 눌러 새 탭으로 그 뷰어를 열어야 함. 그래프를 떠나지 않고 읽고 싶음

## 목표

- 홈 그래프: 홈 문서는 초록 홈 영토 하나, 프로젝트는 프로젝트마다 영토 하나(A′)
- 두 그래프 모두: 다른 작업 공간 영토 제목을 누르면 그 뷰어로, 그 영토의 문서 점을 누르면 옆 패널로 본문

## 하지 않는 것

- 옆 패널에서 다른 작업 공간 문서 고치기, 댓글
- 내 영토 제목 누르기 동작, 영토만 보기 거르기
- 여러 작업 공간을 한 그래프에 합치기(`shared/ideas/home-workspace.md`에서 정함)

## 실패로 보는 것

- 프로젝트 그래프(4180)의 영토, 클러스터 배치와 모양이 달라짐
- 범례에서 끈 클러스터가 영토에서 빠지는 것(0.8.4), 실시간 반영(0.8.5)이 깨짐

## 견준 방법

- 홈 그래프 프로젝트 표시: A(클러스터), A′(영토), B(영토 + shared·private 점), C(점 하나), D(영토 + 클러스터 + 문서 점). A′를 고름. 까닭은 `shared/ideas/home-graph-projects.md`
- 문서 보기: 가운데 창, 옆 패널, 정보 상자. 옆 패널을 고름. 까닭은 `shared/ideas/cross-workspace-jump.md`
- 바깥 문서 본문을 얻는 길
  - 빌드가 실음(고름): 빌드가 제목을 얻으려고 이미 그 파일을 읽음. 상대 뷰어가 꺼져 있어도 읽힘. 홈 노트가 직접 가리킨 문서만이라 양이 적음
  - 서버가 그때그때 읽어 줌: 늘 최신이나 서버가 다른 작업 공간 파일을 읽는 길을 새로 열어야 함
  - 상대 뷰어 서버에서 받기: 포트가 달라 CORS가 필요하고, 상대가 꺼져 있으면 못 읽음

## 바꾸는 곳

### `viewer/build.mjs`

- `extTitles`를 만들 때 읽은 본문을 `extTexts`에 함께 실음(같은 파일, 같은 경로 검사)

### `viewer/template.html`: 홈 모드 영역

- `D.mode === 'home'`이면
  - 홈 작업 공간 폴더와 맨 위 문서는 모두 `home` 영역
  - 바깥 문서는 프로젝트마다 영역 하나(영역 키 `p:<프로젝트 이름>`)
  - 맨 위 문서는 클러스터 없이 홈 영토 안의 점(`rootless`). 범례 이름은 `home`
- 영역 키는 문자열 그대로 두고 폴더 이름을 바꾸지 않음. 범례에서 숨긴 폴더 저장값(`fv-graph3`)이 이어지게
- 프로젝트 영역은 클러스터 원과 이름표를 그리지 않음. 영토 모양과 점 가두기를 위해 안 보이는 원 하나는 둠
- 프로젝트 영역 색은 회색 한 가지, 아이콘은 폴더, 이름표는 프로젝트 이름
- 영역 자리: 홈은 왼쪽 가운데, 프로젝트는 오른쪽에 위아래로
- 범례: 프로젝트마다 칩 하나(폴더 아이콘, 이름, 문서 수). 누르면 그 프로젝트를 숨기고 보임
- 바깥 문서 이름표는 늘 켜지 않고 다른 점처럼 확대해야 보임
- 프로젝트 모드는 이 분기를 타지 않음

### `viewer/template.html`: 영토 제목과 옆 패널(두 모드 모두)

- 다른 작업 공간 영역(프로젝트 모드의 `home`, 홈 모드의 `p:*`) 제목
  - 누르면 그 뷰어 그래프를 새 탭으로 엶. 꺼져 있으면 지금 알림을 그대로 씀(`openExternal`)
  - 올리면 밑줄과 손가락 커서
- 바깥 점을 누르면 옆 패널(지금 정보 상자는 닫음). 내 점을 누르면 옆 패널을 닫고 지금 정보 상자
- 옆 패널
  - 그래프 판 오른쪽에 붙고 그래프를 밀지 않고 덮음
  - 머리: 점 색, 제목, 작업 공간 표시와 경로, 닫기
  - 본문: 문서 화면과 같은 `md()` 렌더링. 읽기만
  - 바닥: "이 문서를 가리키는 내 문서 N개", "<작업 공간> 뷰어에서 열기"
  - 닫기: X, Esc
  - 너비: 처음 440px, 최소 320px, 최대 그래프 판의 80%. 왼쪽 가장자리 끌기, 두 번 누르면 처음 너비, 화살표 24px. 너비는 `localStorage`(뷰어마다)에 기억
  - 본문이 없으면(빌드가 못 읽음) "본문을 읽지 못했습니다"와 열기 단추만
- 실시간 반영으로 그래프를 다시 그려도 열린 패널은 유지. 그 점이 사라지면 닫음

## 만드는 사람에게 맡기는 것

- 안 보이는 프로젝트 원의 크기와 영토 여백. 프로젝트 영토가 홈보다 눈에 띄지 않게
- 홈 맨 위 문서 점이 클러스터 원에 붙지 않게 떨어뜨리는 방법
- 범례가 study 클러스터를 덮는 것: 맞춤(fit)이 범례를 피하는지 보고, 안 되면 별도 이슈로
- 좁은 화면(세로로 쌓이는 화면)에서 옆 패널: 그래프 판 전체 너비로

## 확인

- `npm test`, `claude plugin validate .`
- 홈 뷰어와 프로젝트 뷰어를 이 저장소 코드로 띄워 화면 확인. 다크 모드 포함
- 프로젝트 그래프 모양이 전과 같은지 스크린샷으로 견줌
- 범례 끄고 켜기, 실시간 반영, 패널 너비 끌기와 기억
