# 구현 계획

기능 하나의 구현 단계. 다 만들면 끝나는 문서다.

## 여기에 넣는 것

- 단계별 할 일과 체크 목록, 확인 방법

## 여기에 넣지 않는 것

- 프로젝트 전체의 순서 → `shared/roadmap.md`
- 왜 이렇게 만드나 → `shared/design/`

## 파일 이름과 상태

- 파일: `영문-기능.md`
- `type: plan`, `status`: 제안, 확정, 진행 중, 완료, 접음
