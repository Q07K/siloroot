# 이슈 상태는 열림, 보류, 해결, 안 고침

## 맥락

문서만 보고 일이 시작 전인지, 진행 중인지, 끝났는지 알 수 있어야 한다. 이슈는 열림과 해결 둘뿐이면, 알지만 지금 안 고치는 것이나 다른 일을 기다리는 것을 나타낼 수 없다. 사용자: "보류나 대기 같은 거 필요할 듯".

## 정한 것 (사용자, 2026-11-25)

| status | 뜻 | 본문에 적을 것 |
| --- | --- | --- |
| 열림 | 겪었고 원인을 찾거나 고치는 중 | 겪은 일, 찾은 것 |
| 보류 | 알지만 지금은 안 고친다. 다른 일을 기다리는 대기도 여기 | 까닭, 무엇을 기다리나, 언제 다시 보나 |
| 해결 | 고쳤다 | 원인, 고친 것, 다시 안 나게 한 것 |
| 안 고침 | 고치지 않기로 했다 | 까닭 |

## 버린 것

- 대기를 따로 두기: 결국 "지금은 안 고친다"라서 보류와 같다. 무엇을 기다리는지만 적으면 된다.
