# 결정

결정 하나에 문서 하나. 팀이 "왜 이렇게 됐지?"를 여기서 찾는다.

## 여기에 넣는 것

- 무엇을 왜 정했나, 버린 것
- 그 결정의 근거가 된 측정값
- 반영 상태: 어디에 반영됐나(코드, 문서), 아직인가

## 여기에 넣지 않는 것

- 정하기 전의 논의 → 개인 영역의 논의 기록
- 작은 결정 → 그 아이디어나 설계 문서의 "정한 것" 표
- 작업 일지에 결정 내용을 다시 쓰지 않는다(경로만)

## 파일 이름과 상태

- 파일: `영문-주제.md`
- `type: decision`, `status`: 제안, 확정, 바뀜(뒤집으면 새 결정 기록이 대체하고 서로 잇는다)

## 쓰는 틀

```markdown
---
type: decision
status: 확정
created: YYYY-MM-DD
related: []
---

# 결정 한 줄

## 맥락

## 정한 것 (누가, 날짜)

## 버린 것

## 근거

## 반영
- 코드: 아직
- 문서: 아직
```
