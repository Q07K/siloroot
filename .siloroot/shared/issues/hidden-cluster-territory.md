# 범례에서 클러스터를 꺼도 영토가 남는다

## 겪은 일

- 연결 그래프 범례에서 폴더(클러스터)를 끄면 원, 점, 선은 사라지는데 그 클러스터 둘레의 영토는 그대로 남음.
- 사용자: "cluster disable 시키면 영토가 사라져야하는데 안사라지고 유지됨".
- 0.8.1(영토 도입)부터 있던 문제.

## 원인

- 영토 모양(`areaShapes`)이 범례에서 끈 폴더(`GS.hidden`)를 보지 않고 모든 클러스터 원으로 그림.
- 범례 칩을 누르면 `refresh`가 원, 점, 선의 표시만 바꾸고 영토는 다시 그리지 않음.
- 영토의 클러스터를 모두 끈 채 그래프를 열면 영토 g가 아예 만들어지지 않아, 다시 켜도 채울 자리가 없음.

## 해결

- 땅 씨앗(`landSeeds`)에 폴더 이름을 붙임.
- 그리는 쪽(첫 그리기, `drawAreas`)만 `areaShapes(hulls, nodes, GS.hidden)`로 끈 클러스터를 뺌.
- 영토의 클러스터를 모두 끄면 빈 g를 둠(`off`). 다시 켜면 `drawAreas`가 채움.
- `refresh`가 `drawAreas`를 부름.
- 배치, 그림 크기 맞추기, 선 길 찾기, 영토 밀어내기는 그대로 모든 클러스터를 봄. 끄고 켜도 자리가 바뀌지 않음.

## 확인한 것

| 경우 | 결과 |
| --- | --- |
| `shared/ideas` 하나 끔 | shared 영토 모양이 바뀜, private는 그대로 |
| 다시 켬 | 처음 모양과 같은 `d` |
| shared 클러스터 모두 끔 | 영토와 이름표가 비고, 다시 켜면 처음과 같음 |
| private 클러스터 모두 끄고 새로 고침 → 하나 켬 | 빈 g로 열리고, 켜면 영토와 이름표가 그려짐 |
| 하나 끈 채 다른 클러스터를 끔 | 끈 클러스터의 땅이 되살아나지 않음 |

## 남은 것

- `(맨 위)` 클러스터는 private 영토에 속함. private 폴더만 꺼서는 private 영토가 다 사라지지 않음.
- 가장 가까운 클러스터를 끄면 영역 README 점이 그려진 영토 밖에 놓일 수 있음.
- 노드 울타리와 선 길 찾기는 끈 클러스터의 땅도 그대로 피함.

## 다시 안 나게

- 범례로 숨기는 것을 더할 때는 그 모양을 그리는 함수가 `GS.hidden`을 보는지, `refresh`가 그것을 다시 그리는지 함께 봄.
